# GLAZE UI V1.6 Conformance

GLAZE UI V1.6 (`1.6.0`) is the current Stable Glaze UI conformance target. GLAZE UI `1.5.1` is the immediately preceding known-good Stable rollback baseline, not the current consumer target.

A consumer is conformant only when its exact repository revision satisfies the applicable V1.6 design, accessibility, interaction, responsive/form-factor, platform, authority-boundary, privacy/security, rollback, release, and production gates. Conformance fails closed when required evidence is missing, stale, unsupported, or bound to a different revision.

Promotion of the shared design system to V1.6.0 does not automatically make any downstream GoreeCloud application conformant. Each consumer must explicitly target `1.6.0` and produce fresh repository-local exact-revision V1.6 adoption and acceptance evidence for its supported platforms and production boundary.

The shared V1.6 qualification contains **24 verified obligations, 0 unverified, and 0 not applicable** for the governed scope. Final security acceptance, deterministic artifact provenance, immutable publication, and byte-for-byte release readback are also accepted. These shared qualifications do not establish a downstream consumer's own performance, device, rendered/native, accessibility, deployment, or production acceptance.

Privacy Shield, Wardveil Security, Everkeep, GoreeCloud Identity, GoreeCloud Mesh, GoreeCloud Policy, applications, services, platforms, and other authoritative systems retain authority over their own truth domains. Glaze UI governs presentation and interaction without manufacturing underlying system truth.
