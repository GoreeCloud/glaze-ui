# GLAZE UI V1.4 Conformance

GLAZE UI V1.4 — Optical Material & Chromatic Depth (`1.4.0`) is the current Stable Glaze UI conformance target. GLAZE UI V1.3 (`1.3.0`) remains the immediate known-good Stable rollback baseline, not the current target.

A consumer is conformant only when its exact repository revision satisfies the applicable V1.4 design, accessibility, interaction, responsive/form-factor, platform, performance, fallback, and production gates. Conformance must fail closed when required evidence is missing, stale, or bound to another revision.

Promotion of the shared design system to V1.4 does not automatically make any downstream GoreeCloud application conformant. Each consumer must explicitly target `1.4.0` and produce repository-local evidence for its supported platforms and production boundary.

The human optical/material, manual keyboard/focus, human-operated assistive-technology, representative workflow, physical-device/OEM/compositor, native-renderer observation, and physical-device performance/power qualification intentionally deferred from V1.4.0 remains V1.4.1 work. That deferral is not passed V1.4.0 evidence and does not waive consumer-specific qualification.

Privacy Shield, Wardveil, Everkeep, GoreeCloud Identity, and other GoreeCloud domain authorities retain authority over their own truth. Glaze UI governs presentation and interaction without manufacturing, strengthening, or replacing underlying system truth.
