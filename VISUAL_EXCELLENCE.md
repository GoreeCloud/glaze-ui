# GLAZE UI V1.0 — Visual Excellence

V1 quality is judged by clarity, hierarchy, restraint, balance, rhythm, optical alignment, legibility, consistency, interaction confidence, and accessibility—not by maximizing effects.

Glaze Material should create depth and continuity only where it improves interaction. Dense readable content remains solid. Strong visual moments are reserved for meaningful hierarchy and must degrade gracefully under accessibility and performance constraints.

Human visual review remains required where GoreeCloud acceptance policy calls for it.
