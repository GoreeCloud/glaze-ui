Conformance

Stable semantics protect beauty and usability

Identity, tokens, surfaces, states, accessibility, privacy, resilience, product personality, and purpose-built Mobile/Tablet/Desktop/TV fidelity remain mandatory.

A Glaze UI label never substitutes for conformance. Every GoreeCloud application is required to be an original GoreeCloud-owned native implementation at the product and application layer and to implement the applicable current Stable Glaze UI contract. Mature technical foundations may remain only within narrowly justified dependency boundaries; inherited upstream product UI and product architecture do not satisfy native or Glaze UI conformance.

Stable qualification also depends on current Wardveil Security, Privacy Shield, and Everkeep integration for the application's supported scope. Production conformance must be supported by current implementation and validation evidence.

Adoption

1.4 is Stable and is the production target.

Every GoreeCloud-controlled user-facing application is required to target the current Stable Glaze UI contract as part of its native GoreeCloud implementation. Older Stable consumer pins are migration-required rather than grandfathered production exceptions. A new Stable Glaze UI release reopens the affected consumer's conformance work until the controlled migration and applicable source, rendered, native, and real-device evidence are accepted.
