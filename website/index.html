Glaze UI 1.1.0

Beautiful by design. Consistent by contract.

Glaze UI is GoreeCloud's shared visual and interaction system: layered, rounded, fluid, accessible, privacy-conscious, and designed to preserve product personality instead of flattening every application into the same screen.

Explore componentsView source

Material structure + liquid depth and fluidity + One UI ergonomics + GoreeCloud privacy, identity, and simplicity.

Foundations

Depth with restraint

Glaze uses five intentional surface levels. Translucency is selective; readability, performance, hierarchy, and fallback behavior determine the surface.

CanvasAtmospheric application background
SolidHigh-readability surface
RaisedElevated solid panel
GlazeSelective translucent layer
OverlayAttention-priority surface

Adaptive

Compact, Medium, Expanded, and Wide layouts transform navigation and density rather than simply shrinking.

Accessible

Visible focus, practical 44px targets, reduced motion, forced-colors resilience, semantic naming, and solid fallbacks are part of the contract.

Private

No tracking UI dependencies. Remote fonts, scripts, and icons are prohibited unless explicitly justified and documented.

Components

Shared semantics, flexible composition

Glaze UI defines behavior and state vocabulary while allowing each GoreeCloud product to keep its own role, information architecture, imagery, and personality.

Actions

Buttons preserve accessible names, focus visibility, and practical target sizing.

Input

Placeholder text never replaces a visible label.

Adoption

Version-specific by design

Stable GoreeCloud applications should identify the exact Glaze UI version they target, expose automated contract evidence, and document any approved exception with its reason, impact, fallback, and review condition.
