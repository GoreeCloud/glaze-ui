# GLAZE UI V1.0 — Glaze Sans

Glaze Sans is the GoreeCloud type-family identity used where approved by platform and licensing requirements. V1 typography must prioritize legibility, system scaling, language coverage, 200%+ text behavior, clear hierarchy, and platform-native fallbacks.

Typography must never be required to communicate state through shape alone, and user font-size/accessibility preferences must not be suppressed. Platform acceptance determines where Glaze Sans is used versus native system typography.
