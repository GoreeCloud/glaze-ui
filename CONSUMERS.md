# GLAZE UI V1.0 Consumers

The machine-readable authority for current consumer state is `consumers/registry.json`.

The required target for every applicable GoreeCloud user-facing consumer is **GLAZE UI V1.0** (`1.0.0`). Following the namespace reset, existing consumers require fresh repository-local V1 adoption and acceptance evidence. No consumer is production-eligible merely because GLAZE UI V1.0 is the official platform target.
