# Glaze UI 2.2.0 — Stable Contract

**Lifecycle status:** Stable  
**Stable semantic version:** 2.2.0  
**Previous Stable implementation baseline:** Glaze UI 2.1.0  
**Promoted from:** 2.2.0-candidate.1  
**Accepted visual source:** `0411b0f6dd877aea30e2c5674e1acde0105fd97b`  
**Rollback baseline:** 2.1.0

Glaze UI 2.2.0 promotes the validated 2.2 Candidate design-system surface without rewriting its accepted implementation provenance. Candidate-named source files remain preserved promotion inputs; `css/glaze-2.2.0.css` and `js/glaze-2.2.0.mjs` are the Stable consumer entrypoints.

## Stable scope

The Stable 2.2.0 design-system promise includes the bounded System Shell, the complete 32-component contract catalog, Foundation/Structure/Overlay/Signature/Intelligence reference presentation, Universal Search and Control Center reference interactions, migration compatibility contract, performance/System Glaze budget, Optical Reachability presentation, source-pinned visual regression, and the bounded Android handheld native reference accepted during the 2.2 Candidate line.

The Stable scope is a design-system contract. It does not claim that every downstream GoreeCloud product has already migrated, that every operating system has a complete native shell implementation, or that product backends such as authentication, search indexing, notifications, privacy, security, or intelligence are implemented by Glaze UI itself.

## Presentation rule

**Solid where users read or make explicit critical decisions. Glazed where users interact with transient navigation, command, search, or feedback chrome.**

The Optical Reachability presentation approved for 2.2 preserves readable solid content planes, restrained optical depth, sculpted reachable controls, contained selected states, Deep Dark hierarchy, explicit Critical System presentation, and accessibility semantics that outrank decorative material.

## Accessibility and input contract

Stable 2.2 retains the Candidate acceptance requirements for keyboard, pointer, touch, RTL, 200% text, Reduced Motion, Reduced Transparency, Increased Contrast, Forced Colors, Touch Assistance, focus restoration, non-color semantic state, and target floors of at least 48 px for touch-oriented shell controls and 56 px for Touch Assistance/far-view contexts where applicable.

## Human Visual Excellence

Human Visual Excellence was explicitly **Accepted** for immutable source revision `0411b0f6dd877aea30e2c5674e1acde0105fd97b` on 2026-09-01. The approval is recorded in `acceptance/2.2-visual-review.md`. Stable promotion may rely on that decision only while source-pinned regression proves presentation continuity from the approved source.

## Consumer boundary

No downstream application is promoted by declaration. Glaze UI 2.2.0 becoming Stable changes the required design-system target for GoreeCloud-controlled user-facing consumers, but each consumer remains separately gated by repository-local implementation evidence, automated validation, rendered/native/accessibility acceptance as applicable, and product release/deployment approval.

## Compatibility and migration

Migration from 2.1.0 is governed by `MIGRATION_2_1_TO_2_2.md` and `contracts/migration/glaze-2.1-to-2.2.json`. The design-system migration path is additive at the Stable boundary; downstream production eligibility is still application-specific.

## Stable entrypoints

- Web presentation: `css/glaze-2.2.0.css`
- Runtime: `js/glaze-2.2.0.mjs`
- Stable acceptance: `acceptance/2.2-stable.md`
- Lifecycle authority: `registry/lifecycle.json`
- Visual baseline authority: `contracts/regression/visual-baselines-2.2.json`

## Release and rollback

Stable promotion is valid only for the exact final revision that passes the required promotion workflows. Release/tag traceability must subsequently bind `v2.2.0` to the approved Stable source according to GoreeCloud release procedure. If a blocking regression is found before a corrected 2.2 release is established, the documented rollback target is Glaze UI 2.1.0.

Glaze Motion remains separately Experimental and is not promoted by Glaze UI 2.2.0.
