# GLAZE UI V1.5 Acceptance

GLAZE UI V1.5 / `1.5.0` is the current Stable design-system release when the governed V1.5.0 promotion is authoritative on `main`. `VERSION`, `registry/lifecycle.json`, `GLAZE_UI_V1_5.md`, `contracts/v1.5/stable-scope.json`, and `acceptance/v1.5-stable.md` are the controlling repository authorities for that lifecycle state.

The accepted V1.5.0 implementation is anchored to exact reviewed Development revision `ee1032a0822ab8e103f8afe48e5c1859fde65cc9`. Sixteen human/runtime/accessibility/privacy/performance-transition/platform obligations are accepted for the bounded V1.5.0 Stable scope through real evidence and explicit source-impact continuity.

By project-owner release-scope decision, `performance-representative-budget` and `platform-posture-continuity` are moved to V1.5.1. They are not represented as passed for V1.5.0. Accordingly, V1.5.0 does not claim measurement against the newly approved Glaze UI Performance Budget v1.0 and does not claim representative foldable/posture target-runtime acceptance.

Stable source authority includes the inherited V1.4.1 optical/web foundation, the V1.5 Context + Capability Awareness runtime entrypoint, governed provider/capability authority boundaries, contextual composition/navigation/actions/controls, accessibility precedence, constrained-runtime and connectivity continuity, explicit non-automatic fallbacks, privacy-safe diagnostics, lifecycle records, and the retained V1.4.1 rollback boundary.

No downstream GoreeCloud application becomes V1.5.0-conformant or production-eligible automatically. Each consumer must explicitly target the current Stable release and satisfy its own repository-local exact-revision acceptance boundary for supported platforms.
