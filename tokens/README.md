# GLAZE UI Token Authority

GLAZE UI V1.1 / `1.1.0` remains the current Stable GoreeCloud consumer target. Existing Stable and inherited token files continue to serve that governed baseline where applicable.

GLAZE UI V1.2 token files are Candidate development inputs and are non-consumer-eligible until a separate governed lifecycle promotion occurs. `tokens/glaze-v1.2-core.candidate.json` is the bounded V1.2 ownership and composition index: it points semantic token families to their existing source files and does not duplicate raw token values or create a competing value authority.

The core Candidate manifest currently consolidates ownership for optical color references, atmosphere, material, frost, blur, material opacity, spacing, density, radius, shadow/elevation, typography, Crystal icon size/stroke, Motion duration, and inherited semantic-color meanings. V1.2-specific state-token ownership and complete form-factor token ownership remain explicitly unestablished and cannot be inferred from unrelated token files.

Token presence or alias resolution alone does not establish V1.2 conformance, Release Candidate status, Stable promotion, native parity, production acceptance, or downstream consumer eligibility. Exact-revision validation and the applicable product/platform acceptance gates remain required.
