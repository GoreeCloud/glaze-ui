## Approved visual rule

- Content planes remain solid and content-first.
- Interaction chrome may use perceptible translucent Glaze Material.
- Accent and semantic color coding remains visible through tint, borders, icons and state treatment.
- Reduced Transparency / Solid removes translucency and blur.
- Forced Colors remains authoritative.
- Increased Contrast, Reduced Motion, Large Text and Touch Assistance retain their precedence.
- Material Budgets and performance fallbacks remain binding.

## Objective promotion requirements

Stable promotion requires all of the following on the promotion revision:

- canonical release-state validation;
- Glaze UI repository validation;
- semantic color contract;
- icon identity and construction contracts;
- 2.1 runtime tests and Material Budgets;
- six canonical rendered reference flows;
- interaction and visual-invariant regression;
- resilience/exception-state acceptance;
- source-pinned screenshot pixel regression with unchanged thresholds;
- Android native structure/build/install/runtime acceptance;
- preserved 48 dp general and 56 dp Touch Assistance target floors.

## Boundary

This design-system Stable promotion does not establish downstream application production eligibility. No downstream application is promoted by declaration; each consumer must complete its own 2.1 migration and application-specific acceptance.
