# GLAZE UI V1.4.0 Stable Acceptance

**Decision date:** 2026-09-13  
**Decision:** Accepted as Official Stable, subject to machine-verifiable release gates in this repository.  
**Consumer eligible:** Yes  
**Human validation:** Deferred to V1.4.1 by owner direction; not represented as passed evidence.

## Accepted technical scope

- V1.3 Stable inheritance remains intact.
- The V1.4 Optical Engine is additive and does not replace the established token system or public component API.
- Optical values are deterministic and bounded.
- Forced Colors and Reduced Transparency fail closed to a solid accessible treatment.
- Increased Contrast suppresses decorative tint/warmth and increases protection.
- Environmental memory tint influence is capped at 0.08.
- The Optical Engine does not require telemetry or remote context.
- Stable CSS and runtime entrypoints are present.
- Release-authority files must agree on `1.4.0` before promotion.

## Explicitly unclaimed for V1.4.0

No claim is made that human optical review, subjective polish review, manual assistive-technology qualification, representative physical-device qualification, or real-device performance validation has passed for V1.4.0. Those activities are tracked by `GLAZE_UI_V1_4_1_HARDENING.md`.

## Consumer boundary

Glaze UI v1.4.0 being Stable does not automatically mark a GoreeCloud application Stable. Each application/service must adopt the current Stable Glaze UI target and provide repository-local conformance/acceptance appropriate to its supported surfaces and platforms.
