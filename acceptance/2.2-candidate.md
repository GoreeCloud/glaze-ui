## Objective Candidate checks

The exact-head Candidate workflow verifies at minimum:

- repository `VERSION` remains exactly `2.1.0`;
- lifecycle `currentStable` remains `2.1.0`;
- lifecycle `activeCandidate` is exactly `2.2.0-candidate.1`;
- the Candidate release remains non-consumer-eligible;
- the 2.2 shared state model, priority, System Shell hierarchy, Deep Dark anchors, accessibility fallbacks, and System Glaze budget remain machine readable;
- Critical System does not require decorative backdrop blur;
- the ordinary shell budget remains one dominant Glaze panel plus no more than three small floating Glaze controls unless explicit context requires an exception;
- the bounded System Shell runtime and rendered reference pass executable behavior, responsive, material, and accessibility checks;
- all 32 component contracts remain `2.2.0-candidate.1` Candidate and conform to the closed 2.2 contract schema;
- Foundation, Structure, Overlay, Signature, and Intelligence rendered references preserve their documented responsive, semantic, keyboard, focus, touch, large-text, RTL, resilience, and fallback behavior;
- Signature and Intelligence semantics remain explicit: generated content remains identified, provenance/source affordances remain available where applicable, destructive Universal Search actions require a second explicit activation, and deterministic retrieved results are not visually collapsed into generated interpretation;
- the migration contract remains additive semantic refinement with explicit consumer adoption work, keeps 2.1.0 as the Stable rollback target, and does not authorize production migration while 2.2 is Candidate;
- the migration catalog remains exactly 32 contracts: 8 Foundation, 8 Structure, 6 Overlay, 5 Signature, and 5 Intelligence;
- Universal Search preserves immediate query focus, keyboard traversal, deterministic-results-first behavior, source provenance where available, explicit confirmation for destructive actions, Escape cancellation semantics, and focus restoration;
- Control Center preserves programmatic toggle state, native range values, dominant-panel exclusivity with Search, and focus restoration;
- performance and Glaze-budget source/runtime/rendered checks remain fail-closed;
- the bounded Android-native reference builds and its emulator/runtime acceptance path remains independent from retained 2.1 Stable evidence;
- the six representative visual states are rendered from immutable Candidate source revision `83bc9241590a47547d51369ea0812e40bb96775d` on the same runner as the exact current revision and pass pixel thresholds without treating the result as Human Visual Excellence approval;
- no remote presentation dependency is introduced by the Candidate implementation;
- capabilities without implementation and evidence remain Pending/Planned rather than being inferred as Stable;
- Glaze Motion remains separately Experimental.
