## Scope and acceptance

1.4 promotes Mobile, Tablet, Desktop, Wide Desktop, and TV form-factor semantics while retaining the complete 1.3 expressive/material/accessibility foundation. The canonical rendered matrix covers Mobile 390×844, Tablet 820×1180, Desktop 1280×900, Wide Desktop 1600×1000, and TV 1920×1080 in light/dark, plus TV reduced-motion and forced-colors focus resilience and the retained base reference cases.

## Native applicability assessment

The Glaze UI repository ships platform-neutral semantics, CSS/reference implementations, and validation—not an Android, iOS/iPadOS/tvOS, native Linux, or television-hardware runtime. Native/real-device execution is therefore not an applicable design-system-core gate for 1.4. Consumer applications must still complete their own native mapping and representative device acceptance before claiming application-level 1.4 conformance or production readiness.

## Compatibility and migration

1.4 is a compatible minor release. 1.3 semantics remain valid. Existing consumers are not migrated automatically; Manager remains on 1.3, the public website consumer remains on 1.1, Tasks remains an Adoption Candidate against 1.3, and unverified consumers remain unverified until separately audited.
