## Decision

GLAZE UI V1.5.0 is accepted for the bounded Stable scope defined by `contracts/v1.5/stable-scope.json`.

The owner-directed release boundary intentionally moves two previously open qualification items to V1.5.1 rather than manufacturing evidence or treating them as passed:

- `performance-representative-budget`
- `platform-posture-continuity`

Accordingly, V1.5.0 Stable does not claim measurement/pass against the newly approved Glaze UI Performance Budget v1.0 and does not claim representative foldable/posture target-runtime acceptance.

## Explicit non-claims

This Stable acceptance does not establish:

- V1.5.0 measurement/pass against `Standard — Glaze UI Performance Budget.md` v1.0;
- foldable/posture target-runtime acceptance;
- automatic downstream GoreeCloud consumer conformance or migration;
- tag or GitHub Release publication;
- deployment acceptance;
- production cutover acceptance for any consumer;
- authorization, consent, permission, or operational authority for Glaze UI itself.

Those boundaries must remain explicit in repository, task, and downstream adoption records.
