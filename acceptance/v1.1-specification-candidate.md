## Native-platform boundary

This candidate does **not** claim that V1.1 has been implemented or accepted as a new platform-native Android, iOS, watch, wearable, TV, spatial, or other native adapter. Existing V1 native-platform records are not relabeled as V1.1 evidence. Any future V1.1 native implementation or conformance claim requires its own exact-revision native evidence before that claim is made.

This boundary does not prevent the shared V1.1 semantic and optical contract from being reviewed as a design-system candidate; it prevents unsupported platform-native claims.

## Environmental Color Memory boundary

Environmental Color Memory remains optional and unimplemented in this first candidate. Conformance does not depend on environmental content sampling. No remote color derivation, persistent sample history, or semantic inference is authorized by this candidate.

## Release boundary

Passing the checked gates establishes a deterministic V1.1 specification plus an isolated, rendered, accessibility-validated web implementation candidate with explicit project-owner optical approval. It does **not** change `VERSION`, make V1.1 current, publish a Stable release, establish Production Stable implementation, establish platform-native V1.1 acceptance, or upgrade any downstream GoreeCloud application by declaration.
