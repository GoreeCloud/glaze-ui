# Glaze UI 1.5 Candidate Acceptance Record

## Release identity

- Candidate version: `1.5.0-candidate`
- Stable baseline preserved: `1.4.0`
- Development pull request: `#81 — Add Glaze UI 1.5 motion, interaction, and materials contracts`
- Candidate scope: adaptive color, iconography, motion/interaction, and material/depth semantics.
- Wear OS remains outside the 1.5 Candidate acceptance scope.

## Source validation

The Candidate is required to pass the exact-revision Glaze UI CI stack, including adaptive color, iconography, motion, material/depth, typography, enforcement, form-factor, consumer-registry, Firefox integration, public-site, and retained Stable rendered-reference checks.

Passing source validation does not by itself promote 1.5 or authorize production conformance.

## Motion and material rendered acceptance

`reference/candidate-1.5.html` is the isolated visual target for 1.5 motion/material evidence. It does not alter the Stable 1.4 reference experience.

`reference/candidate-1.5-acceptance.html` and `scripts/validate_candidate_1_5_rendered.py` fail closed on representative Candidate behavior including:

- Canvas-adjacent Solid and Raised content surfaces;
- Functional Glass with bounded backdrop treatment;
- Clear Glass over visually rich media;
- scrim/Overlay depth ordering;
- semantic enter, state, press/focus, and determinate-progress motion roles;
- light and dark appearances at Mobile 390×844, Tablet 820×1180, Desktop 1280×900, and TV 1920×1080 representative viewports;
- reduced-motion substitution with animation and transition travel removed;
- portable reduced-transparency behavior using the explicit Glaze UI web adapter;
- reduced-transparency behavior independently from reduced motion;
- constrained-performance fallback that removes backdrop filtering without removing hierarchy or information;
- absence of horizontal overflow across the representative matrix.

## Acceptance boundaries

This rendered suite proves the platform-neutral web reference contract only. It does not substitute for consumer-specific native mapping, real-device testing, application accessibility review, product performance testing, or downstream migration evidence.

Material appearance cannot manufacture privacy, security, resilience, or coordination truth. Privacy Shield, Wardveil Security, Everkeep, and GoreeCloud Mesh remain authoritative for those underlying states; Glaze UI remains authoritative for their presentation contract.

## Promotion decision

The Candidate remains unpromoted until the complete exact-head CI stack, including the dedicated 1.5 rendered acceptance gate, succeeds and the remaining 1.5 Candidate promotion requirements are reviewed. Glaze UI 1.4.0 remains the current Stable production baseline and current consumer target.

## Rollback

Because 1.5 remains isolated Candidate work, rollback is branch/PR-level: close or revert the Candidate changes without altering the 1.4.0 Stable baseline or forcing consumer migration.
