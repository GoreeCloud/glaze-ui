# GLAZE UI V1.0 — Interaction States

V1 components must define clear default, hover where applicable, focus, active/pressed, selected, disabled, loading, error, success, warning, and destructive/confirmation behavior as relevant.

Focus must remain visible and keyboard-reachable. Disabled state must not be confused with unavailable system truth. Destructive actions require appropriate confirmation based on consequence, and state changes must remain perceivable without relying on color, transparency, or motion alone.
