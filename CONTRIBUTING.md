# Contributing to GLAZE UI

GLAZE UI V1.5 (`1.5.1`) is GoreeCloud's current Official, Stable, consumer-eligible shared visual and interaction design system. V1.5.0 is the immediate known-good Stable rollback baseline, while V1.4.1 and earlier Stable releases remain preserved historical provenance.

Current Stable work must preserve accessibility, semantic clarity, platform-native behavior, exact-revision evidence, consumer-governance boundaries, presentation-only authority, and GoreeCloud repository/revision-control requirements. Changes to the V1.5 line must preserve the current V1.5.1 Stable Context + Capability Awareness contract, its inherited reviewed V1.5 presentation behavior, and its fail-closed authority boundaries unless a separately governed later release explicitly supersedes them.

Do not change `VERSION`, `registry/lifecycle.json`, official Candidate/Stable entrypoints, consumer eligibility, or downstream conformance as a side effect of ordinary implementation or qualification work. Lifecycle promotion requires a separate governed decision with fresh exact-revision evidence. Human, representative-runtime, physical-device, accessibility, and performance gates may be supported by automation, but automation must not impersonate the required review or acceptance authority.

GLAZE UI V1.5.1 is Stable. Its two qualification expansions—representative performance qualification and platform/posture continuity—are accepted only for their reviewed shared environments and evidence anchors. That shared Stable qualification does not automatically establish downstream consumer conformance, deployment acceptance, physical-device acceptance, or production readiness.

New behavior that is not already part of the current V1.5.1 Stable authority must remain in an explicitly governed Development, Candidate, or follow-up namespace until formal promotion and must be accompanied by applicable contracts, tests, rendered/native evidence, accessibility coverage, migration/rollback considerations, and documentation. Downstream applications remain independently responsible for repository-local conformance and production acceptance; Glaze Stable status does not transfer consumer acceptance.

Git history remains the required revision audit trail. Historical release and Candidate records may retain their original version language when they are explicitly historical or provenance-only; current front-door guidance must always derive lifecycle truth from `VERSION` and `registry/lifecycle.json`. At this revision, current Stable authority is GLAZE UI V1.5 / `1.5.1`, with `1.5.0` retained as the immediate rollback baseline.


## Active V1.6 Release Candidate

GLAZE UI V1.6 / `1.6.0-rc.1` is the active governed Release Candidate. It is non-consumer-eligible and does not supersede V1.5.1 as the current Stable consumer target.

Changes that could affect V1.6 qualified behavior, evidence continuity, authority boundaries, or release identity must be treated as release-sensitive. A changed exact candidate requires applicable revalidation. Documentation-only or CI maintenance work must preserve the qualification source/evidence bindings and must not silently convert the RC into Stable, production-ready, published, deployed, or consumer-accepted state.
