# Contributing to GLAZE UI

GLAZE UI V1.6 (`1.6.0`) is GoreeCloud's current Official, Stable, consumer-eligible shared visual and interaction design system. GLAZE UI `1.5.1` is the immediate known-good Stable rollback baseline; earlier Stable and Release Candidate records remain preserved historical provenance.

Current Stable work must preserve accessibility, semantic clarity, platform-native behavior, exact-revision evidence, presentation-only authority, privacy/security truth boundaries, consumer-governance boundaries, and GoreeCloud repository/revision-control requirements. Changes to qualified V1.6 behavior or release-sensitive controls require fresh exact-head validation.

Do not change `VERSION`, `registry/lifecycle.json`, Stable entrypoints, consumer eligibility, immutable release identity, or downstream conformance as an incidental side effect. A future lifecycle transition requires a separate governed decision and current exact-revision evidence.

The V1.6.0 shared qualification is **24 verified / 0 unverified / 0 not applicable**. Final security acceptance, deterministic artifact provenance, immutable `v1.6.0` publication, and post-publication byte readback are preserved release evidence. None of those shared passes automatically establish downstream consumer conformance, deployment acceptance, or production readiness.

New behavior outside the accepted V1.6.0 Stable boundary must remain in an explicitly governed Development, Release Candidate, patch, or successor namespace until formally accepted. Downstream applications remain independently responsible for repository-local V1.6 conformance and production acceptance.

Git history remains the required revision audit trail. Historical V1.5.1, V1.6 RC, qualification, and publication records must remain immutable provenance; current front-door guidance derives lifecycle truth from `VERSION` and `registry/lifecycle.json`.
