# Contributing to GLAZE UI

GLAZE UI V1.4 — Optical Material & Chromatic Depth (`1.4.0`) is GoreeCloud's current Official Stable and consumer-eligible shared visual and interaction design system. GLAZE UI V1.3 (`1.3.0`) remains the immediate Stable rollback baseline. The planned next patch line is V1.4.1, which owns the human/manual/subjective/assistive-technology/physical-device qualification intentionally deferred from V1.4.0.

Current Stable work must preserve accessibility, semantic clarity, platform-native behavior, deterministic fallbacks, privacy-bounded capability negotiation, exact-revision evidence, consumer-governance boundaries, and GoreeCloud repository/revision-control requirements.

Do not change `VERSION`, `registry/lifecycle.json`, Official Stable entrypoints, consumer eligibility, or downstream conformance as a side effect of ordinary implementation work. Lifecycle promotion requires an explicit governed decision and exact-revision automated evidence. Human/manual evidence may be deferred only when the governing release policy explicitly says so; deferred evidence remains unverified and must never be represented as passed.

V1.4 corrective work should remain compatible with the governed Stable contract wherever possible. V1.4.1 qualification may add patch-level fixes discovered by human/manual verification, but it must preserve provenance and must not rewrite V1.4.0 evidence retroactively.

Downstream applications remain independently responsible for repository-local adoption, platform conformance, accessibility, performance, rollback, and production acceptance. Shared design-system Stable status never grants application production eligibility automatically.

Git history remains the required revision audit trail. Historical release and Candidate records may retain their original version language when they are explicitly historical or provenance-only; current front-door guidance must agree with `VERSION` and `registry/lifecycle.json`.
