Resilience

Uncommon and failure states stay calm, explicit and actionable without hiding uncertainty behind polished chrome.

Exceptional states

These are design-system reference states, not claims about a live GoreeCloud service. Each state keeps its meaning visible through text, shape and action hierarchy.

Service unavailableA required capability cannot be reached right now.
Session expiredIdentity must be re-established before protected work continues.
Sync conflictTwo versions need an explicit resolution; neither is silently discarded.
Destructive actionPermanent removal requires a clear confirmation path.
OfflineNetwork-dependent actions are deferred while local context remains readable.
No resultsThe empty state explains what happened and gives a useful next action.
