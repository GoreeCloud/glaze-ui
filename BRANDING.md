# GLAZE UI V1.0 — Branding

## Official identity

- **Product name:** GLAZE UI V1.0
- **Short product name:** Glaze UI
- **Machine version:** `1.0.0`
- **Repository:** `GoreeCloud/goreecloud-glaze-ui`

The V1 identity is the only current Glaze UI product identity in the active repository and current GoreeCloud documentation.

## Official repository asset

The current repository identity mark is maintained under:

`assets/identity/official/facet/glaze-ui-mark.svg`

Identity assets must be used according to the active Glaze UI identity, iconography, icon-construction, color, material, accessibility, and visual-excellence contracts. Alternate or superseded release branding must not be presented as current.

## Naming rules

Use **GLAZE UI V1.0** where the official versioned product identity is required. Use **Glaze UI** in ordinary prose where the version is not material. Use `1.0.0` for machine-readable version fields.

Branding does not establish production acceptance or downstream conformance. Those states require the applicable V1 evidence.
