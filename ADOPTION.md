# GLAZE UI V1.5 Adoption

The current Glaze UI adoption target is **GLAZE UI V1.5** (`1.5.1`). GLAZE UI V1.5.0 (`1.5.0`) is the immediate known-good Stable rollback baseline. Earlier Stable releases remain historical provenance and must not be presented as the current adoption target.

Adoption requires repository-local implementation evidence, exact-revision validation, rendered or native acceptance as applicable, accessibility acceptance, supported-form-factor validation, and product-specific production approval. Importing tokens, copying styles, changing a version label, or relying on Glaze UI's own Stable lifecycle does not establish downstream conformance.

Consumers remain fail-closed in `consumers/registry.json` until V1.5.1-specific evidence is recorded for the exact consumer revision and applicable target environment. The shared V1.5.1 Stable promotion does not grant downstream conformance automatically.

V1.5.1 preserves the reviewed V1.5 Context + Capability Awareness behavior and closes the two bounded shared qualification expansions recorded in `contracts/v1.5.1/stable-scope.json` and `acceptance/v1.5.1-stable.md`. Representative performance qualification and platform/posture continuity are accepted only for their reviewed shared environments; consumers retain their own applicable performance, platform, accessibility, deployment, and production evidence obligations.

Historical V1.5.0, V1.4.1, and earlier qualification remains valid release provenance for the exact versions and scopes accepted. It does not replace V1.5.1 consumer migration, repository-local application acceptance, native/platform evidence, accessibility review, product lifecycle approval, or production release evidence.
