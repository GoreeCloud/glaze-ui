# GLAZE UI V1.4 Adoption

The current Glaze UI adoption target is **GLAZE UI V1.4** (`1.4.1`). GLAZE UI V1.4.0 (`1.4.0`) remains available as the immediately preceding known-good Stable rollback baseline.

Adoption requires repository-local implementation evidence, exact-revision validation, rendered or native acceptance as applicable, accessibility acceptance, supported-form-factor validation, and product-specific production approval. Importing tokens, copying styles, or changing a version label does not establish conformance.

Consumers remain fail-closed in `consumers/registry.json` until V1.4.1-specific evidence is recorded for the exact consumer revision. The shared V1.4.1 Stable promotion does not grant downstream conformance automatically.

The V1.4.1 human/manual/physical qualification is Stable design-system evidence only. It does not replace repository-local application migration, native/platform acceptance, product lifecycle approval, or production release evidence.
