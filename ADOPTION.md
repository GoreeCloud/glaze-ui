# GLAZE UI V1.5 Adoption

The current Glaze UI adoption target is **GLAZE UI V1.5** (`1.5.0`). GLAZE UI V1.4.1 (`1.4.1`) is the immediately preceding known-good Stable rollback baseline. Earlier Stable releases remain historical provenance and must not be presented as the current adoption target.

Adoption requires repository-local implementation evidence, exact-revision validation, rendered or native acceptance as applicable, accessibility acceptance, supported-form-factor validation, and product-specific production approval. Importing tokens, copying styles, changing a version label, or relying on Glaze UI's own Stable lifecycle does not establish downstream conformance.

Consumers remain fail-closed in `consumers/registry.json` until V1.5.0-specific evidence is recorded for the exact consumer revision and applicable target environment. The shared V1.5.0 Stable promotion does not grant downstream conformance automatically.

V1.5.0 accepts the bounded Context + Capability Resolution scope while preserving V1.4.1 as rollback authority. The V1.5.1 Development follow-up remains non-consumer-authorizing and has two external qualification obligations still pending: representative performance-budget evidence and representative platform/posture continuity evidence.

Historical V1.4.1 human/manual/physical qualification remains valid release provenance for that version only. It does not replace V1.5.0 consumer migration, repository-local application acceptance, native/platform evidence, accessibility review, product lifecycle approval, or production release evidence.
