# GLAZE UI V1.4 Component Status

**Official design-system baseline:** GLAZE UI V1.4 / `1.4.0`  
**Inherited V1 component catalog:** 32 components  
**Catalog source:** `contracts/components/v1/catalog.json`  
**Catalog namespace origin:** GLAZE UI V1.0  
**V1.4 lifecycle:** Official Stable

The canonical V1 component catalog remains the 32-component namespace introduced at the V1 reset. V1.4 does not silently replace or renumber that catalog. Instead, V1.4 promotes shared optical-material, runtime-capability, accessibility-composition, browser-adaptation, fallback, and presentation behavior that components may consume through the Stable V1.4 entrypoints.

A component's presence in the inherited catalog does not by itself prove that every downstream implementation has adopted or physically qualified V1.4 behavior. Consumer applications and native renderers retain their own conformance and acceptance boundaries.

Human/manual/physical-device component verification that depends on subjective optical judgment, human interaction, assistive technology, actual native rendering, or representative hardware is part of the V1.4.1 qualification follow-up and remains unverified until evidence is captured.

For release authority, use `VERSION`, `GLAZE_UI_V1_4.md`, `registry/lifecycle.json`, and `acceptance/1.4.0.md` rather than the historical lifecycle strings embedded in the original V1 catalog.
