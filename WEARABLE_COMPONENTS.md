# GLAZE UI V1.0 — Wearable Components

Wearable adaptations derive from the V1 semantic component model but may use platform-specific controls and navigation patterns. Components must preserve action meaning, accessibility labels, focus/reachability, confirmation behavior, and readable state at small display sizes.

No former candidate wearable asset is a current V1 contract; wearable acceptance is regenerated against the V1 namespace.
