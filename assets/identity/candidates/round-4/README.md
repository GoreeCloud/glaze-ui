- `glaze-ui-prism.svg` — an asymmetric adaptive prism with a protected viewport.
- `glaze-ui-strata.svg` — offset interface strata joined by a single adaptive spine.

These files intentionally remain under the non-canonical candidate path required by `IDENTITY.md`. They must not be used as the public favicon, production mark, or canonical Glaze UI identity until one exact candidate is explicitly approved and promoted through the documented identity workflow.

All candidates are dependency-free SVG, contain no script or remote resource, and are designed for light/dark and monochrome-derivative evaluation. The preview board is static HTML/CSS and loads only these repository-local candidate files.
