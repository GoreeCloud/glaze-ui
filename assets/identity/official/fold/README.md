# Glaze UI Fold Identity

Fold is the approved official visual identity for Glaze UI.

## Authoritative source

- `glaze-ui-mark.svg` — canonical full-color standalone mark.
- `glaze-ui-mark-monochrome.svg` — canonical monochrome construction.
- `glaze-ui-lockup.svg` — canonical horizontal Glaze UI lockup.

SVG source is authoritative. PNG, favicon, profile, document, and application derivatives are generated artifacts and must not be hand-edited.

## Required derivatives

Generate standalone mark PNGs at 16, 24, 32, 48, 64, 128, 256, 512, and 1024 px. Generate lockup PNGs for website/document use at 600, 900, and 1200 px widths. Generate profile-safe 512 and 1024 px square exports and validate the mark inside both circular and square crops.

## Usage

Use the standalone mark for profile/avatar, favicon, compact application/system identity, badges, and constrained surfaces. Use the horizontal lockup for website headers, documentation title areas, public identity treatments, and layouts where the Glaze UI name should be explicit.

## Surface variants

The full-color mark is preferred on light and neutral surfaces. The monochrome mark is required for monochrome printing, high-contrast contexts, and environments where brand colors cannot be reproduced reliably. Dark-surface presentation must preserve the approved Fold silhouette and internal white fold detail.

## Prohibited modifications

Do not redraw, rotate, skew, stretch, add effects, replace colors ad hoc, remove the internal fold detail, substitute upstream branding, or create unrelated Glaze UI marks. All official derivatives must trace back to this directory.
