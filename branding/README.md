# Glaze UI Brand Identity

This directory is the canonical source for all Glaze UI visual identity assets.

## Purpose

Glaze UI is the GoreeCloud design system authority. Its icons, logos, artwork, and brand assets are maintained independently from individual applications.

## Asset Categories

```
branding/
├── icons/
│   ├── glaze-symbol.svg
│   ├── glaze-symbol-mono.svg
│   └── application-icons/
├── logos/
│   ├── glaze-logo.svg
│   ├── glaze-wordmark.svg
│   └── glaze-lockup.svg
├── artwork/
│   ├── wallpapers/
│   ├── illustrations/
│   └── promotional/
└── exports/
    ├── favicon/
    ├── app-icons/
    └── social/
```

## Design Requirements

- SVG-first source files
- Light and dark variants
- Accessibility-aware contrast
- Consistent with Glaze UI design tokens
- Reusable by all GoreeCloud applications
