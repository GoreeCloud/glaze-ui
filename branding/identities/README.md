# GoreeCloud Foundation Identities

This directory contains shared identity definitions used across the GoreeCloud ecosystem.

## Identities

### Glaze UI

Design language and interface system.

### Privacy Shield

Privacy and data protection identity.

### Wardveil Security

Security and protection identity.

## Ownership

Foundation identities should maintain their own artwork standards and reusable assets. Product repositories consume these identities rather than creating duplicate branding.
