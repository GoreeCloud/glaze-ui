# Glaze UI Icon System Standards

## Purpose

The Glaze UI icon system defines how official GoreeCloud foundation and application identities are created, maintained, and consumed.

## Principles

- SVG-first source assets
- One canonical source repository
- Applications consume assets; they do not duplicate branding
- Consistent optical sizing
- Consistent geometry and spacing
- Light and dark variants where required
- Accessibility-friendly naming

## Required Variants

Each identity may provide:

- Primary symbol
- Dark variant
- Monochrome variant
- App icon variant
- Export formats

## Ownership

Glaze UI owns shared visual system assets. Product repositories reference these assets instead of maintaining separate copies.
