# Glaze UI Identity Concepts - Round 01

Status: **Review candidates only - not approved, canonical, deployable, or public-site artwork.**

This directory contains three materially different Glaze UI identity concepts developed under `IDENTITY.md` and issue #16. They remain isolated from the public design site, favicon metadata, deterministic publication, and canonical identity paths.

Approval must identify one exact candidate ID and its recorded Git blob SHA in `manifest.json`. Technical validation only confirms source safety and review isolation; it does not approve the artwork.
