# GoreeCloud Application Identity Registry

This directory defines the ownership and usage model for application icons consumed by GoreeCloud products.

## Rules

- Application identities are owned centrally.
- Applications consume official assets instead of creating duplicate branding.
- Every icon should provide light, dark, monochrome, and app-icon variants where applicable.
