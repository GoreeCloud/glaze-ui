# GLAZE UI V1.0

**Machine version:** 1.0.0  
**Release identity:** Official reset baseline  
**Production acceptance:** Revalidation required

GLAZE UI V1.0 establishes the sole current Glaze UI product identity and resets the active repository namespace to V1. The baseline retains the intended design-system direction—Glaze Material, ergonomic spatial hierarchy, connected transformation, adaptive expression, accessibility-first interaction, System Shell, and the 32-component catalog—without treating earlier release identities as current V1 evidence.

A future production release claim must bind the V1.0 identity to an exact accepted post-reset revision and applicable CI/acceptance evidence.
