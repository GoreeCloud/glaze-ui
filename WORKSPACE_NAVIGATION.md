# GLAZE UI V1.0 — Workspace Navigation

V1 workspace navigation supports persistent or adaptive rails/sidebars, Universal Search, contextual tools, and system-level panels without obscuring durable content hierarchy. Navigation placement adapts to form factor, reachability, window size, and platform convention.

Selection, focus, current location, panel exclusivity, and escape/back behavior must be explicit. Navigation must remain usable with Reduced Motion, Reduced Transparency, large text, RTL, keyboard, pointer, touch, and assistive input.
