# Glaze UI Evidence Validity

Current Glaze UI conformance and production UI acceptance claims depend on evidence that is both attributable and current.

Evidence used for a current passing claim must identify when it was observed and the producer- or applicable-policy-defined time through which it remains valid. Missing or expired required validity fails closed. A consumer such as GoreeCloud Mesh may evaluate the declared validity boundary but may not extend, replace, or override it.

This contract does not create application conformance, runtime acceptance, production approval, release authorization, or Stable promotion by itself.
